# ⚙️ QualityTrack - Backend API

API REST para la plataforma **QualityTrack**, diseñada para la digitalización, trazabilidad y control de calidad en el mecanizado de piezas industriales.

## 🛠️ Stack Tecnológico
* **Lenguaje:** Python
* **Framework:** Flask
* **Base de Datos:** MySQL
* **Autenticación:** JWT / Sesiones

## 🚀 Alcance del MVP
* Gestión de usuarios y roles (Administrador, Operario de Taller, Inspector de Calidad).
* Endpoints para alta, consulta y cambio de estado de Órdenes de Trabajo (OT).
* Vinculación de documentación técnica (planos en PDF).
* Trazabilidad y registro cronológico de eventos por orden.
